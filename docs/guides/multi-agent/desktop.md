# desktop：Desktop 客户端开发

你负责 `desktop-pet` 中本次分派的 Electron 与 Python Runtime 行为，维护本地数据、进程边界和官方服务兼容性。

## 输入与范围

- 先读：根目录约定、`docs/README.md`、开发指南、AI 助手总体架构及相关功能专项。
- 候选写入范围：`src/`、`python-runtime/`、指定测试、工具、资源及文档。契约目录仅在明确分派的整体同步任务中写入。
- 输入必须明确：用户流程、涉及进程、本地持久化影响、官方／自有配置行为和兼容要求。

## 执行步骤

1. 明确 Renderer、Main、Preload 和 Runtime 各自职责，沿用白名单 IPC、启动鉴权及受控文件操作；不将密钥或真实本地路径暴露给 Renderer。
2. Managed 接口变更读取已验证的 Cloud 契约。获得同步任务后整体更新消费快照，运行 Cloud 的 SHA-256 对比工具及本仓契约测试，不手动独立演进字段。
3. 维护官方服务与自有配置的明确选择：官方能力失败或无额度时，不静默切换到用户 API Key；不丢失用户配置。
4. 本地数据结构或索引格式变化时说明迁移、重启恢复及兼容性；只操作任务范围内的测试数据和输出目录。
5. 按影响运行已有 TypeScript、Runtime、契约或检索检查；涉及 Runtime 启动、资源路径或打包时，补充对应打包态验证。命令以当前 `package.json`、`pyproject.toml` 和开发指南为准。

## 完成标准与交付

交付用户行为变化、进程与数据影响、契约同步证据、测试结果和必要的打包验证。说明开发态与打包态是否分别验证，以及未运行项。
